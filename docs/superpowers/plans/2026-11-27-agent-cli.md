# Agent CLI implementation plan

Design: `docs/superpowers/specs/2026-11-27-agent-cli-design.md`.
Branch: `feat/agent-cli`. Tests first per step.

1. **internal/slack groundwork**
   - `ConvertMessage(text)`: the mrkdwn + rich_text pair `postMessage` and
     `EditMessage` both build; both call it.
   - `SearchMessagesPage(ctx, query, SearchOptions)`: page and sort;
     `SearchMessages` delegates.
   - `(*Client).TeamURL()`: auth.test's url, for `slackurl.Build`.
   - `WaitOutRateLimit` recognises `*rateLimitError`; `RetryRateLimited`.
   - `edge.User`: `tz`, `real_name`, `profile.title` (seen on live
     users/info and users/search today).
2. **cmd/slk session and output**: `agent_cli.go` (dispatch, flags, JSON
   writer, JSON errors, exit codes), `agent_session.go` (token, remint,
   connect, lazy Grid org routing), `agent_time.go`, `agent_names.go`
   (batched name resolution, message JSON).
3. **Read commands**: `agent_read.go` — search, channels, users, history,
   thread, mentions.
4. **Write commands**: `agent_write.go` — send, reply, react, edit, delete;
   mention translation through `compose.Model`; own-message guard.
5. **main.go**: dispatch before `debuglog.Init`; help text.
6. **Docs**: `docs/agent-cli.md`; AGENTS.md table entries for every new
   helper.
7. **Gates**: `go build ./...`, `go vet ./...`, `go test ./... -race`,
   `golangci-lint run`, `gofmt -l .`.
8. **Live verification** on Taras's workspace: reads anywhere; writes only in
   his self-DM, every test message deleted.
